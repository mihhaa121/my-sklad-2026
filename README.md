# Мой склад · 2026 — Version 12.4 Inventory Control

Основа: стабильная Version 12.3 Inventory Workflow.

## Изменения 12.4
- Склад показывает отдельно: Куплено, Продано, По учёту, Физически дома и Расхождение.
- По учёту = Куплено − Продано. Ручная инвентаризация не переписывает историю закупок.
- Enter в поле «Физически дома» сохраняет число, но больше не закрывает карточку.
- После сохранения появляется краткое «✓ Сохранено».
- Новая закупка увеличивает Куплено и физический остаток; новая продажа увеличивает Продано и уменьшает физический остаток.
- Escape закрывает открытые модальные окна закупки/продажи и открытую карточку каталога eBay.
- Кнопка Закрыть/× продолжает работать как раньше.
