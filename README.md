# Мой склад · 2026 — Version 12 Modular

Это первая безопасная модульная версия, собранная из рабочей Version 11.2.

## Что изменено
- Внешний вид вынесен из index.html в `css/app.css`.
- JavaScript разнесён на отдельные файлы по существующим слоям программы.
- Порядок выполнения кода сохранён таким же, как в Version 11.2.
- Ключи localStorage НЕ изменены, поэтому существующие локальные данные должны остаться совместимыми.

## Файлы
- `index.html` — каркас интерфейса и экраны.
- `css/app.css` — все стили.
- `js/legacy-warehouse.js` — старая база партий/продаж v3; пока оставлена ради совместимости.
- `js/ebay-catalog.js` — eBay Active Listings, карточки, импорт/экспорт каталога.
- `js/linked-architecture.js` — связанная база Version 11: orders, sales, stock adjustments и связь закупок со складом.
- `js/stock-sales-ui.js` — группировка склада по моделям и интерфейс связанной продажи.
- `js/workflow-controls.js` — последние исправления 11.2: закупки, физический остаток, сохранение eBay quantity, управление окнами.

## Важно
Version 12.0 — это структурная миграция, а не новая логика. Сначала убедитесь, что она ведёт себя как 11.2. После этого можно постепенно удалить legacy-слой и перейти к единой базе products/variants/orders/listings/sales.

## Установка на GitHub Pages
Загрузите в корень репозитория `index.html` и папки `css`, `js`, `data`, сохраняя структуру. GitHub Pages автоматически загрузит относительные файлы.
