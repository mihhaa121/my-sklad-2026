# Мой склад · 2026 — Version 12.3 Inventory Workflow

Рабочая модульная версия поверх стабильной 12.2.

## Изменения 12.3
- Возвращена явная кнопка **+ Новая закупка** и Order с несколькими товарными строками.
- Экран **Продажа** получил поиск по физическому складу и выбор точного варианта.
- **История** показывает продажи со всех площадок.
- Физический остаток редактируется прямо в Складе; Enter/изменение сохраняет значение в localStorage.
- Ручной физический остаток используется как текущий доступный остаток для продажи.
- Кнопки склада переименованы в **Объявления** и **Записать продажу**.
- Навигация центрирована на широком экране.
- Поле физического количества сделано компактным.

Ключ данных сохранён: `mikhail_warehouse_2026_v11_arch`.
